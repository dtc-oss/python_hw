# Прогнозирование стоимости недвижимости

Используется Ridge-регрессия с обработкой пропусков, кодированием категориальных признаков и логарифмированием цены (price).
Интерфейс - Streamlit.
Добавлено API с помощью FastAPI для модели (из задания hw9). API получает характеристики недвижимости и возвращает прогноз её стоимости.

## Запуск
Запуск API:
```
python -m uvicorn api:app --host 127.0.0.1 --port 8000 --reload
```
адрес
`http://127.0.0.1:8000/docs`

Запуск Streamlit
```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Использовался Python 3.15 (scikit-learn 1.9.1)
Переобучение модели (чтобы переобучить нужно положить рядом файл `realty_data.csv`, отсутствует из-за большого размера):
```
python train_model.py
```

Получение прогноза (пример):
```
python predict.py
```

## Признаки модели

- Числовые: общая площадь, количество комнат, этаж, широта и долгота.
- Категориальные: город, населённый пункт, район и микрорайон/жилой комплекс.
- Целевая переменная: `price`.

Площадь и целевая цена логарифмируются, категории кодируются через One-Hot Encoding.
Данные брались из `realty_data.csv` (файл отсутствует из-за большого размера).

Использовано объектов: 98 822
Строк в обучающей выборке: 79 057
Строк в тестовой выборке: 19 765
MAE: 5 229 885 руб.
RMSE: 15 206 247 руб.
R²: 0.827

## Структура

- `api.py` — код API.
- `test_api.py` — тесты API.
- `screenshots` - реализация запросов.
- `train_model.py` — обучение модели.
- `model_utils.py` — подготовка данных и прогноз цены.
- `app.py` — страница Streamlit.
- `predict.py` — пример прогноза через Python.
- `requirements.txt` — библиотеки, которые нужны для запуска.
- `model.joblib` и `metrics.json` — данные модели.
- `realty_data.csv` — данные о недвижимости (файл отсутствует, при переобучении нужно добавить в папку задания).
